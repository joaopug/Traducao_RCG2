# Sobre

Este repositório reúne todos os arquivos utilizados durante o desenvolvimento da tradução de **River City Girls 2** para **Português Brasileiro**.

O objetivo do projeto é oferecer uma localização completa e de alta qualidade, preservando o estilo, o humor e a personalidade dos personagens, além de adaptar recursos gráficos e audiovisuais para proporcionar uma experiência mais natural ao público brasileiro.

Além da tradução dos textos, o projeto também contempla a reconstrução de mangás, edição de vídeos e adaptação de elementos gráficos presentes no jogo.

## Texto

Contém todos os arquivos responsáveis pela tradução do jogo.

Os recursos encontram-se separados entre as versões **Steam** e **Epic Games**, facilitando a manutenção e garantindo compatibilidade entre ambas.

Entre eles estão arquivos exportados dos assets Unity, como:

* I2Languages-resources
* TextMeshPro-level185-254
* TextMeshProUGUI-resources

---

## Fontes

Reúne todos os arquivos utilizados para adaptação das fontes do jogo ao Português Brasileiro.

Inclui:

* Fontes editadas exportadas
* Arquivos de projeto (XCFs)

---

## Mangá

Contém os projetos utilizados na tradução e reconstrução das páginas do mangá presente em River City Girls 2.

Todas as páginas do mangá já foram traduzidas.

---

## Chefes

Contém os projetos de edição dos vídeos de introdução dos chefes.

Todos os vídeos já foram traduzidos para Português Brasileiro.

---

## Gráficos

Reúne os recursos relacionados à tradução de elementos gráficos presentes no jogo.

Atualmente, somente um gráfico foi traduzido.
